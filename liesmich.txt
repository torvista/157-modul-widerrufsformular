=================
BESCHREIBUNG
=================
Die Pflicht zur Vorhaltung einer elektronischen Widerrufsfunktion („Widerrufsbutton“) tritt zum 19.06.2026 in Kraft und gilt für alle Shops mit Online-Bestell- oder Buchungsfunktion, in denen (auch) vom Verbraucherwiderrufsrecht umfasste Waren, Dienstleistungen und/oder digitale Inhalte angeboten werden
Dieses Modul stellt ein frei konfigurierbares Widerrufsformular bereit, das die gesetzlichen Vorschriften ab 19.06.2026 erfüllt.
Bei der Installation werden keine bestehenden Dateien überschrieben, so dass die Installation sehr einfach ist und keine Probleme bei zukünftigen Zen Cart Updates verursachen sollte.

Das Modul verfügt über drei administrative Schnittstellen: 
* Konfiguration > Widerrufsformular für allgemeine Einstellungen
* Webshop > Widerrufsformular erstellen/bearbeiten um das Widerrufsformular anzupassen oder für andere Sprachen zu generieren
* Kunden > Widerrufsformular Dashboard um die gesandten Widerrufe der Kunden zu sehen und auf in Arbeit oder Erledigt zu stellen

Formulare für deutsch und englisch werden bereits bei der Installation vorgeneriert, so dass alles sofort ohne weitere Anpassung einsatzbereit ist.
* Der Kunde erhält nach Absenden des Formulars die vorgeschriebene Bestätigung des Erhalts per Email.
* An die in den Einstellungen hinterlegte E-Mail wird auch der Admin über den Widerruf benachrichtigt.
* In der Zen Cart Administration sind die gesandten Widerrufe ersichtlich und können auf erledigt gestellt werden.

==================
INSTALLATION
==================

Dieses Modul ist nur für die deutsche Zen Cart 1.5.7j Version geeignet

Empfehlung:

Dieses Modul erst in einem Testsystem einbauen und dort konfigurieren/testen und endgültig an die eigenen Wünsche anpassen. Erst dann in einem Liveshop einsetzen! Sichern Sie unbedingt alle Dateien Ihres Shops per FTP und sichern Sie die Datenbank mit phpMyAdmin oder anderen geeigneten Tools!

WICHTIG
Vor dem Einbau dieser Änderungen:
BACKUP von Shop und Datenbank machen!
Keine Haftung, Verwendung auf eigene Gefahr!
BACKUP gemacht? Ok, dann weiterlesen...

Die Installation erfolgt in folgenden Schritten. Halten Sie diesen Ablauf ein!

1. Benennen Sie im Ordner NEUE DATEIEN den Ordner DEINADMIN auf den Namen Ihres Adminverzeichnisses um.
2. Benennen Sie im Ordner NEUE DATEIEN alle Ordner namens DEINTEMPLATE auf den Namen Ihres im Shop aktiven Templates um (z.B. responsive_classic)
3. Loggen Sie sich in Ihre Zen Cart Shopadministration ein.
4. Laden Sie nun die Ordner/Dateien aus dem Ordner NEUE DATEIEN in der vorgegebenen Struktur ins Zen Cart Verzeichnis hoch. Dabei werden keinerlei bestehende Dateien überschrieben.
5. Clicken Sie nun in Ihrer Zen Cart Administration auf irgendeinen Menüpunkt, Sie sollten oben grüne Erfolgsmeldungen sehen.


==================
KONFIGURATION
==================
Unter Konfiguration > Widerrufsformular finden Sie generelle Einstellungen. Tragen Sie die E-Mail-Adresse, an die die Widerrufe gesendet werden sollen unter der Option E-Mail Adresse ein.
Falls Sie das Admin Mail an mehrere E-mail Adressen schicken lassen wollen, geben Sie mehrere Adressen mit Komma getrennt ein
Die sonstigen Voreinstellungen dort können Sie unverändert lassen, außer Sie haben spezielle Anforderungen.

Unter Webshop > Widerrufsformular hinzufügen/bearbeiten sind bereits zwei vollständig den rechtlichen Erfordernissen entsprechende Widerrufsformulare für deutsch und englisch hinterlegt. 
Beschreibung meint immer einen Hilfetext, der im Formular dann durch Mouseover über das jeweilige Fragezeichen eingeblendet wird.
Diese Texte können Sie nach Ihren Wünschen anpassen.


==================
LINK/BUTTON ZUM WIDERRUFSFORMULAR INS TEMPLATE INTEGRIEREN
==================

Der Link zu Ihrem Formular wird Ihnen angezeigt, diesen Link verlinken Sie dann wo auch immer Sie zu diesem Widerrufsformular linken wollen.
Er lautet standardmäßig für die deutsche Sprachversion:
index.php?main_page=widerrufsformular&form_id=1
Und für die englische:
index.php?main_page=widerrufsformular&form_id=2

Der Link muss benannt sein als:
Vertrag widerrufen

Für die Darstellung gilt, dass er auffällig sein muss, daher muss er zumindest fett sein oder als Button dargestellt werden.
Und er muss auf jeder Seite des Shops vorhanden sein.
Empfohlen wird eine Darstellung in der Fußzeile oder wo Sie eben sonst solch wichtige Links in Ihrem Shop vorgesehen haben.

Falls Sie mit EZ Pages Links in der Fußzeile arbeiten, finden Sie im Ordner LINK IN TEMPLATE INTEGRIEREN/IN DER EZ-PAGES FUSSZEILE eine Vorlage für eine entsprechend geänderte Datei.

Falls Sie mit EZ Pages Sidebox arbeiten, finden Sie im Ordner LINK IN TEMPLATE INTEGRIEREN/IN DER EZ-PAGES SIDEBOX eine Vorlage für eine entsprechend geänderte Datei.

Falls Sie mit der Sidebox Information arbeiten, finden Sie im Ordner LINK IN TEMPLATE INTEGRIEREN/IN DER SIDEBOX INFORMATION eine Vorlage für eine entsprechend geänderte Datei.

Für alle anderen Einbindungsarten, fügen Sie in Ihrem Template an der Stelle, wo der Link/Button erscheinen soll Folgendes ein:

<a class="widerrufsbutton" href="index.php?main_page=widerrufsformular&form_id=1">Vertrag widerrufen</a>

Für mehrsprachige Shops kann mit einer entsprechenden Abfrage gearbeitet werden:

<?php if ($_SESSION['language']=='german') {?>
  <a class="widerrufsbutton" href="index.php?main_page=widerrufsformular&form_id=1">Vertrag widerrufen</a>>
<?php  } else { ?>
	<a class="widerrufsbutton" href="index.php?main_page=widerrufsformular&form_id=2">Cancel contract</a>
<?php } ?> 

Die Darstellung des Buttons können Sie dann in folgender Datei auf Ihre Farben oder sonstigen Wünsche anpassen:
includes/templates/DEINTEMPLATE/css/stylesheet_widerrufsbutton.css


==================
WIDERRUFSBEARBEITUNG IN DER ADMINISTRATION
==================

Unter Kunden > Widerrufsformular Dashboard finden Sie später die erfolgreich über das Widerrufsformular abgesandten Nachrichten.
Hier kann der Bearbeiter den enthaltenen Widerruf dann nach der Prüfung und Bearbeitung auch auf erledigt stellen.


==================
WEITERE ANPASSUNG
==================

Um das Widerrufsformular weiter zu stylen die includes/templates/DEINTEMPLATE/css/widerrufsformular.css entsprechend bearbeiten.
Als Hilfe Icon wird folgende Datei mitgeliert:
images/widerrufsformular-help.png
Überschreiben Sie diese Datei mit Ihrer eigenen Grafik.


==================
ABSICHERUNG MIT GOOGLE RECAPTCHA V3
==================

Um das Widerrufsformular gegen Spam abzusichern, können Sie das Modul Google ReCaptcha V3 verwenden, das ohnehin zur Absicherung des Kontaktformulars zu empfehlen ist:
https://www.zen-cart-pro.at/knowledgebase/google-recaptcha-v3-fuer-zen-cart-1-5-7-deutsch/

Falls Sie dieses Modul in Ihrem Zen Cart Shop aktiv haben, passen Sie die beiden Beispieldateien im Ordner OPTIONAL-GOOGLE-RECAPTCHA an die Ihrer Installation an.
Unter Konfiguration > Google ReCaptcha V3 Konfiguration tragen Sie dann unter Aktion je Formularseite zusätzlich die Widerrufsformularseite ein.
So, dass es z.B. so aussieht:
contact_us=default, product_reviews_write=default, widerrufsformular=default


==================
DEINSTALLATION
==================

Um das Modul komplett zu entfernen:
1. Alle von diesem Modul neu hinzugefügten Dateien vom Server löschen
2. Im Ordner UNINSTALL die uninstall.sql mit einem Texteditor öffnen und den Inhalt kopieren
3. Kopierten Inhalt absenden unter Tools > SQL Patches installieren
